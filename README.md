# 나우다 제휴사 안내 포털

제휴사가 업체ID와 접속코드로 들어와 **소식·FAQ를 보고 1:1 문의를 남기는** 사이트입니다.
관리자는 같은 사이트의 관리자 화면(`#/admin`)에서 소식·FAQ·문의·접속코드를 관리합니다.

```
네이버 QR / 단축 URL
   ▼
GitHub Pages (docs 폴더)  ── 화면
   ▼  JSON 요청
구글 앱스 스크립트 (apps_script 폴더) ── 로그인 확인, 저장 (HTML을 내보내지 않아 상단 안내 줄 없음)
   ├─ 구글 시트: 업체 · 소식 · 문의 · FAQ · 관리자 · 접속기록 탭
   └─ 구글 드라이브: 이미지 · 첨부 · 본문 폴더 (시트와 같은 폴더 안)
```

기존 통계 앱(`nowda-data`)과는 시트·비밀값이 모두 따로입니다. 통계는 나중에 연결합니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `docs/` | 화면. GitHub Pages가 이 폴더를 그대로 보여 줍니다. 빌드 과정 없음 |
| `docs/config.js` | **사이트 설정** (서버 주소, 분류 목록, 연락처) |
| `apps_script/Code.gs` | 서버 코드. 구글 시트의 앱스 스크립트에 붙여 넣습니다 |

## 체험 모드

`docs/config.js`의 `API_URL`이 비어 있으면 서버 없이 **체험 모드**로 동작합니다(데이터는 그 브라우저에만 저장).

- 제휴사: `G001` / `12345678`
- 관리자: 주소 끝에 `#/admin` → `admin` / `admin12345`

내 컴퓨터에서 보기: 터미널에서 `python3 -m http.server 8765 --directory docs` 실행 후 http://localhost:8765

## 처음 설치 (한 번만)

### 1. 구글 시트와 서버 만들기
1. 구글 드라이브에 폴더 `nowda-partner`를 만들고, 그 안에 새 구글 시트를 만듭니다(이름: `nowda-partner-board` — 기존 통계 파일과 겹치지 않게).
   이미지·첨부 폴더도 이 폴더 안에 자동으로 생깁니다. 나중에 계정을 옮길 때 이 폴더만 넘기면 됩니다.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs`의 내용을 모두 지우고, 이 저장소의 `apps_script/Code.gs` 내용을 붙여 넣은 뒤 저장(⌘S)합니다.
4. 왼쪽 **프로젝트 설정(톱니바퀴)** → 시간대를 `(GMT+09:00) 서울`로 바꿉니다.
5. 시트로 돌아와 새로고침하면 메뉴에 **나우다 포털**이 생깁니다.
   **나우다 포털 → 처음 설정**을 누르고 권한을 승인합니다.
   ("확인되지 않은 앱" 화면이 나오면 **고급 → nowda-partner-board(으)로 이동**을 누릅니다. 내가 만든 스크립트라 괜찮습니다.)
6. **나우다 포털 → 관리자 추가**로 관리자 아이디·이름·비밀번호(10자 이상)를 만듭니다.

### 2. 서버 배포
1. Apps Script 화면 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(톱니바퀴) → **웹 앱**을 고릅니다.
3. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한: 모든 사용자**로 설정하고 배포합니다.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

### 3. 화면에 서버 주소 넣기
`docs/config.js`의 `API_URL: ''` 따옴표 안에 위 주소를 붙여 넣고 저장합니다.

### 4. GitHub Pages 배포
1. 이 폴더를 GitHub `nowda-partner` 조직의 저장소(`nowda-partner.github.io`)에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, 브랜치 `main`, 폴더 **/docs**로 저장합니다.
3. 1~2분 뒤 https://nowda-partner.github.io/ 에서 열립니다.

### 5. 네이버 QR / 단축 URL
네이버 QR코드 관리에서 연결 주소를 `https://nowda-partner.github.io/` 로 정합니다.
관리자 화면 주소는 `https://nowda-partner.github.io/#/admin` 입니다(제휴사에게는 알리지 않습니다).

### 6. 업체 등록과 접속코드 발급
1. 시트 **[업체]** 탭에 `업체ID · 업체명 · 구분 · 카테고리 · 사용(Y)` 순서로 304곳을 붙여 넣습니다.
   업체ID는 기존 규칙(공영 `G`, 민영 `M` + 숫자 3자리)을 그대로 씁니다.
2. 관리자 화면 **제휴사 관리 → 미발급 일괄 발급**을 누르면 접속코드(숫자 8자리)가 만들어집니다.
   **창을 닫기 전에 CSV로 내려받으세요.** 시트에는 암호화된 값만 남아 다시 볼 수 없습니다.
3. 잃어버린 업체는 같은 화면에서 **재발급**합니다. 재발급하면 이전 코드와 로그인 중이던 화면은 바로 막힙니다.

## 운영 중 알아둘 것

- **서버 코드(Code.gs)를 고친 뒤에는** 배포 → **배포 관리** → 연필 아이콘 → 버전 **새 버전** → 배포를 눌러야 반영됩니다. 주소는 그대로입니다.
  (새 배포를 만들면 주소가 바뀌니 `config.js`도 바꿔야 합니다.)
- **화면(docs)을 고친 뒤에는** GitHub에 올리면 1~2분 뒤 반영됩니다. 이미 열어 둔 화면은 새로고침해야 바뀝니다.
- 소식의 이미지·첨부파일은 드라이브 **"링크가 있는 모든 사용자"** 공개로 저장됩니다(주소를 아는 사람만 볼 수 있음).
  **1:1 문의 첨부는 공개하지 않고** 로그인한 본인과 관리자만 내려받을 수 있습니다.
- 같은 업체ID·관리자 아이디로 5번 틀리면 30분 동안 잠깁니다.
- 로그인은 12시간 유지됩니다.
- 개인정보는 받지 않습니다. 문의 작성 화면에도 이름·연락처를 적지 말라고 안내합니다.

## 시트 탭 설명

| 탭 | 내용 | 직접 고쳐도 되는 열 |
|---|---|---|
| 업체 | 업체ID, 업체명, 구분, 카테고리, 사용(Y/N), 발급일, 해시, 마지막접속 | 업체명·구분·카테고리·사용 |
| 소식 | 관리자 화면에서 쓴 글 | 관리자 화면에서 고치세요 |
| 문의 | 제휴사가 남긴 문의와 답변 | 관리자 화면에서 고치세요 |
| FAQ | 질문·답변·순서·숨김 | 관리자 화면 권장 |
| 관리자 | 관리자 계정(비밀번호는 암호화) | 사용 열(N이면 로그인 불가) |
| 접속기록 | 로그인 성공·실패 기록 | 지워도 됩니다 |

**해시 열은 지우거나 고치지 마세요.** 지우면 그 업체는 접속할 수 없게 됩니다(접속 중지와 같은 효과).
